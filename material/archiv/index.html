BookMonkey API

Wir stellen für die vorherige 4. und die aktuelle 1. Auflage eine gehostete HTTP-Schnittstelle bereit, um Datensätze (Bücher) auf einem Server anlegen, lesen, aktualisieren und löschen zu können.

Für die alten Auflagen 1–3 ist diese Schnittstelle nicht mehr online verfügbar. Bitte stelle deine eigene Anwendung auf die BookMonkey API 5 (für die 4. Auflage) oder die neue BookManager API 1 (für die 1. Auflage, 2026) um.

Der Code für die abgeschalteten APIs ist weiterhin auf GitHub verfügbar. Du kannst das Projekt also bei Bedarf lokal installieren:
